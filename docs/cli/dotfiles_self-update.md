## dotfiles self-update

Install the latest published CLI release

### Synopsis

Download the latest public GitHub release, verify its SHA-256 checksum, and replace this executable. Requires Apple Silicon macOS and a writable installation directory. Does not update the configuration checkout.

```
dotfiles self-update [flags]
```

### Examples

```
  dotfiles self-update
```

### Options

```
  -h, --help   help for self-update
```
