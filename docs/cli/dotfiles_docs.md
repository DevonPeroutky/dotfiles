## dotfiles docs

Generate Markdown command reference

```
dotfiles docs [flags]
```

### Examples

```
  dotfiles docs --output docs/cli
```

### Options

```
  -h, --help            help for docs
      --output string   Directory for generated Markdown (default "docs/cli")
```
